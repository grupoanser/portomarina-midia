# Casa Porto Marina · mídia de venda

Fotos, vídeos e criativos da venda da casa no Porto Marina Residence (Ananindeua/PA).

| Pasta | O que guarda |
|---|---|
| `fotos/originais` | Todas as fotos como saíram do celular, sem edição |
| `fotos/selecionadas` | As melhores, escolhidas para anúncio e posts |
| `videos/originais` | Vídeos brutos (tour e pé-direito) |
| `videos/editados` | Vídeos cortados e prontos para anúncio |
| `criativos/anuncios` | Imagens e carrosséis dos anúncios |
| `criativos/posts-perfil` | Os 9 posts do perfil @casaportomarina |
| `book` | Book de vendas em PDF |
| `documentos` | Material de apoio para a venda (sem dados pessoais) |

## Regras
- Nome de arquivo: `AAAA-MM-DD_ambiente_numero` (ex.: `2026-11-19_sala_01.jpg`).
- Não guardar aqui documentos com CPF, RG, dados bancários ou matrícula completa.
- Repositório privado.
